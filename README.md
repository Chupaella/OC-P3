# Booki – Intégration HTML / CSS

## Contexte
Booki est un projet réalisé dans le cadre de la formation Intégrateur Web OpenClassrooms..  
L’objectif était d’intégrer une page web à partir d’une maquette fournie, sans JavaScript, en utilisant uniquement HTML et CSS..

---

## Objectifs pédagogiques
- Structurer une page HTML de manière sémantique
- Réaliser une intégration fidèle à une maquette
- Mettre en place un design responsive
- Utiliser le CSS pour gérer les layouts et les styles
- Garantir une bonne lisibilité et une navigation claire

---

## Technologies utilisées
- HTML5
- CSS3
- Flexbox
- Media queries

---

## Fonctionnalités principales
- Page d’accueil responsive
- Sections Hébergements, Activités et Populaires
- Cartes cliquables avec images et titres
- Adaptation desktop, tablette et mobile
- Navigation simple et accessible

---

## Contraintes du projet
- Aucun framework ou bibliothèque externe
- Pas de JavaScript
- Respect strict de la maquette fournie
- Compatibilité avec les navigateurs modernes

---

## Choix techniques
- Utilisation de balises HTML sémantiques pour améliorer l’accessibilité et le référencement
- Mise en page réalisée principalement avec Flexbox pour une meilleure flexibilité
- CSS organisé par sections pour faciliter la lisibilité et la maintenance
- Approche responsive basée sur des breakpoints adaptés au contenu

---

## Installation et lancement
Aucune installation particulière n’est nécessaire..

1. Cloner le dépôt
2. Ouvrir le fichier `index.html` dans un navigateur

---

## Points forts
- Intégration fidèle à la maquette
- Code HTML clair et structuré
- CSS lisible et organisé
- Bonne adaptation responsive
- Base solide pour des projets front plus complexes
